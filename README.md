## Purpose

This repository contains materials for GitHub Workshop for [Digitorium 2026].

The workshop is designed to introduce conference attendees to the following:
- GitHub platform
- Versioning, and why it's important
- Git, and how it works!

The repository itself was built using the GitHub browser interface. I opted to make the repository public, and to build it in real-time, to provide students with an example of what versioning using Git could look like.
During the workshop, we will review changes and choices I made for content and presentation throughout the life of the building process for the workshop lessons.

## Learning Outcomes

After completing this lesson, learners will be able to do the following: 

1. Explain the concept of versioning, and why it's important in DH work.
2. Describe GitHub, and its purpose and potential role in versioning DH projects.
4. Identify key vocabulary for working with Git and GitHub.
5. Explain key processes for versioning using Git and GitHub.
6. Apply knowledge of Git and  GitHub to `initialize` a new repository, make a `commit`, and `fork` another `repository`.

### Markdown

Notice how I've built this whole lesson plan and resource kit in this text-based language that renders formatting after I commit?

This is called Markdown! Markdown is a pretty cool markup language that allows users to create text-based documents where the formatting is directly encoding.

Text-based document formats (CSV, MD, LaTeX, TXT, STL, XML, JSON, etc.), as opposed to those made with a proprietary format (think PDFs, DOCX, etc.) are much less likely to corrupt over time.
